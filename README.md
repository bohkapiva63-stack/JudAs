# JudAs Media Player 🟢

**JudAs Media Player** — современный медиаплеер с встроенной глубокой интеграцией с приложением **LAMPA**, поддержкой **TorrServer** для онлайн-просмотра торрентов, синхронизацией таймкодов и неоново-зеленым стилем интерфейса.

---

## ✨ Основные возможности

* 🟢 **Неоново-зеленая цветовая гамма (Lampa Accent)** — стилизованный UI плеера.
* ⏱️ **Синхронизация таймкодов** — автоматическая передача позиции и продолжительности просмотра в Lampa REST API (`/requests/lampa.json`).
* 📶 **Переключение качества и дорожек** — выбор разрешения видео, переключение аудиодорожек и субтитров напрямую из приложения Lampa.
* 🚀 **Оптимизированное проигрывание торрентов** — автоматическое предбуферизация потоков TorrServer (`:network-caching=3000`) без фризов.
* 🔌 **Готовый плагин Lampa** — встроенный клиентский плагин `lampa_plugin.js`.

---

## 🛠️ Сборка и релиз

### Сборка через Meson (рекомендуется)
```bash
meson setup build
meson compile -C build
```

### Сборка через Autotools
```bash
./bootstrap
./configure
make
```

---

## 🔌 Подключение плагина к Lampa

1. Запустите JudAs с включенным веб-интерфейсом.
2. В Lampa откройте **Настройки** ➔ **Плагины** ➔ **Добавить плагин**.
3. Укажите адрес:
   `http://<IP_УСТРОЙСТВА_С_ПЛЕЕРОМ>:8080/lampa_plugin.js`
