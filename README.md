# 🎬 JudAs Player v5.0.0 (Material Design 3 Edition)

> **Мощный, мгновенный и красивый медиаплеер для Android TV, смарт-ТВ приставок и смартфонов с глубокой интеграцией в Лампу (Lampa), TorrServer, NUM, Anixart и KinoPub.**

---

## 🌟 Ключевые возможности JudAs Player

### 🏠 1. Главный экран в стиле Vimu / Nova (Home Dashboard)
- **Современный Material Design 3 интерфейс** в фирменной изумрудно-зеленой гамме (`#071A12` / `#10B981`).
- **Блок «Продолжить просмотр»**: интерактивные карточки недавно открытых фильмов с сохраненной позицией, полосой прогресса и точным возобновлением.
- **Медиатека и Хранилища**: доступ к файлам на ТВ, флешках и в папке Загрузок.
- **Сетевой поток / TorrServer**: прямой запуск ссылки на трансляцию или локального сервера (`http://127.0.0.1:8090/stream`).
- **Центр настроек**: глобальный выбор цвета субтитров (Жёлтый OLED / Белый / Серый), размера шрифта, ориентации и AFR.

---

### 📺 2. Боковое меню серий и Умный автогенератор сезонов
- **Выезжающая боковая шторка серий** в стиле Vimu / Лампы.
- **Полная мультимодальность**: подхват плейлистов серий из **Лампы** (`video_list`), **Anixart**, **NUM**, **KinoPub** и локальных плейлистов.
- **Изумрудная подсветка играющей серии (`▶`)**: строгая подсветка ровно одной активной серии.
- **Умный автогенератор серий**: если передана ссылка только на 1 серию (например, `s24e1`), плеер автоматически достраивает весь сезон!
- **Бесконечный накопительный список**: нажатие на кнопку «Вперёд» подтягивает следующую серию и дописывает её в меню без выхода из плеера.

---

### ⚡ 3. Моментальный запуск и 100% Аппаратное ускорение
- **Мгновенный старт воспроизведения (0.5 сек)**: благодаря настроенному буферизатору `DefaultLoadControl` торренты из TorrServer и сетевые стримы открываются моментально.
- **Универсальный `DefaultDataSourceFactory`**: поддержка всех протоколов (`http`, `https`, `content`, `file`, `rtsp`).
- **Прямой GPU рендеринг (`MediaCodec Direct`)**: 100% аппаратная прорисовка кадров через видеочип процессоров TCL, Xiaomi Mi Box, Tox, Amlogic, Realtek, MediaTek.

---

### 🔍 4. Аппаратный Зум / Масштабирование кадра
- **Прямой подгон видеоповерхности (`videoSurface.setScaleX`)**:
  - `Fit (100%)` — оригинальный размер кадра.
  - `Zoom / Crop` — физическое увеличение кадра на **1.335x** для срезания левых и правых черных полос на 4:3 сериалах (*Гриффины, Симпсоны*) или верха/низа на ультрашироких фильмах.
  - `Stretch / Fill` — пропорциональное растягивание на весь TV-экран.

---

### 📊 5. Живой 10Hz OSD-Монитор и Баджи качества
- **Кнопка `( i )`**: открывает интерактивную плашку с обновлением буфера и FPS **10 раз в секунду в реальном времени**.
- **Автоматические плашки качества**: отображение 4K UHD, Dolby Vision, HDR10+, Dolby Atmos, DTS-HD при старте видео.

---

### 🎬 6. Автофреймрейт (AFR) и Субтитры
- **Автофреймрейт**: автоматическое переключение частоты обновления экрана ТВ (23.976 Гц, 24.0 Гц, 50 Гц, 60 Гц) под кадры фильма.
- **Тумблер AFR**: включение/выключение автофреймрейта прямо в меню во время просмотра.
- **Субтитры**: поддержка вшитых дорожек, локальных файлов `.srt`/`.vtt` с функцией удаления, поиска OpenSubtitles, настройки цвета и компенсации рассинхрона.

---

### 🎮 7. Идеальная адаптация под пульт Android TV (D-Pad)
- **Изумрудный фокус (`#10B981`)** без вылезающих рамок.
- **Клик `OK`**: вызывает панель управления без остановки воспроизведения.
- **Двойное нажатие `Back`**: чистый выход обратно в Лампу с сохранением и передачей точного прогресса просмотра (`com.mxtech.intent.result.VIEW`).

---

## 🔌 Интеграция с Лампой (Lampa Plugin)

Чтобы Лампа передавала весь сезон целиком в JudAs Player, добавьте наш плагин в Лампу:

> **Настройки ⚙️ ➔ Плагины ➔ Добавить плагин ➔ Ссылка**:
> `https://raw.githubusercontent.com/judas-player/lampa-plugin/main/judas.js`

## 🛠️ Сборка проекта

Проект собирается с помощью Gradle и подписывается ключом `JudAs-Player.jks` (V1 + V2 Signature):

```bash
./gradlew app:clean app:assembleRelease
```

Скомпилированный APK файл находится по пути:
`app/build/outputs/apk/release/JudAs.Player.v5.0.0-release.apk`
